# SO TIRED ROCK — Expert — hand spec. One line per bar: 16 sixteenths.
# x = a free single (compose.py picks the hand), d = both hands, l/r = that hand, . = rest
#
# ★DOUBLE GRAMMAR (learned on this build, see LOG.md): a double is a HIT, so both hands must
# arrive at it in the same phase, and ideally both needing a DOWN swing. Between two doubles the
# number of singles must be EVEN, and ≡ 2 mod 4 for a down-hit (≡ 0 needs a quarter-note gap
# somewhere so one hand can take two in a row). Backbeat doubles 4 slots apart (1 or 3 singles
# between) can NEVER satisfy this — the first draft had 75 of 99 doubles mixed or upward.
# ⇒ choruses: one down-hit per bar on beat 1, with 6 (simple 8ths) or 10 (guitar 16ths) singles.
# ⇒ streams: 2-bar phrases, hit + 26 sixteenths + breath.
